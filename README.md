# E-Commerce Sales Analysis – Excel

## Project Overview
An Excel-based e-commerce sales analysis project focused on data cleaning, validation, reporting, KPI analysis, and dashboard visualization.

## Business Objectives
- Analyze overall sales performance
- Track monthly revenue and order volume
- Compare category, region, and sales-channel performance
- Identify top-performing products
- Validate and clean transaction data
- Create management-ready KPI reporting

## Excel Skills Demonstrated
- Advanced Excel
- Data Cleaning
- Data Validation
- Power Query concepts
- Pivot Tables / Pivot-style summaries
- KPI Reporting
- Charts and Dashboard Design
- Business Reporting
- Attention to Detail

## Files
- `Ecommerce_Sales_Analysis.xlsx` – complete Excel workbook
- `raw_sales_data.csv` – raw transaction dataset
- `cleaned_sales_data.csv` – cleaned and validated dataset
